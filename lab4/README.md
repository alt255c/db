# Лабораторная работа №4: Физическая реализация базы данных «Теремок ПРО»

## Описание задачи
Студент должен:
* разработать физическую схему БД (DDL);
* определить типы данных, ключи и ограничения целостности;
* реализовать связи между таблицами и правила удаления/обновления данных;
* подготовить начальные и тестовые данные;
* автоматизировать создание и пересоздание базы данных;
* обеспечить соответствие физической схемы результатам ЛР2.

Тестовые данные должны быть достаточны для выполнения последующих лабораторных работ.


## Используемые технологии
*   **СУБД:** PostgreSQL 18.6
*   **Инструмент управления:** pgAdmin 4
*   **Язык генерации данных:** Python 3.12
*   **Библиотеки Python:** `psycopg2-binary` (драйвер БД), `Faker` (генерация реалистичных данных)

## Состав проекта
Проект состоит из трех основных файлов:
1.  **`lab4.sql`** – DDL-скрипт создания схемы. Содержит определение всех таблиц, пользовательских типов (`ENUM`), первичных и внешних ключей, а также ограничений целостности (`CHECK`, `UNIQUE`).
2.  **`initial.sql`** – SQL-скрипт начального наполнения. Заполняет справочники (базовые изделия, начинки, франчайзи, точки продаж) эталонными данными для проверки базовой логики.
3.  **`gen.py`** – Скрипт на Python для генерации тестовых данных. Создает транзакционные записи (поставки, заказы, списания, проверки качества), соблюдая бизнес-правила и контролируя остатки на складах.

## Инструкция по запуску и пересозданию базы данных

### 1. Подготовка окружения
```bash
pip install psycopg2-binary faker
```

### 2. Создание базы данных в pgAdmin
**pgAdmin4** -> **Databases** -> **Create** -> **Database**.
Имя: `teremol_pro`.

### 3. Создание схемы (DDL)
Выволнить lab4.sql

### 4. Начальное наполнение (НСИ)
Выполнить initial.sql

### 5. Генерация тестовых данных
В блоке `if __name__ == "__main__":` настройте параметры подключения к вашей БД:
```python
db_config = {
    'dbname': 'teremok_pro',
    'user': 'postgres',
    'password': 'КАКОЙ-НИБУДЬ_МЕГАСЛОЖНЫЙ_ПАРОЛЬ',
    'host': 'localhost',
    'port': 5432
}
```
Затем:
```bash
python gen.py
```
Если всё ок, в конце выведется: `=== ВСЕ ТЕСТОВЫЕ ДАННЫЕ УСПЕШНО СГЕНЕРИРОВАНЫ ===`.
